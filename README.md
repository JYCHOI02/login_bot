**① 무엇을 만들었는지 (2~3줄 요약)**
파이썬(alert_sender.py)을 이용해 n8n으로 JSON 형식의 보안 경보 데이터를 전송하는 자동화 파이프라인을 구축
n8n의 Code 노드에서 위험도(Level) 기준에 따라 보안 이벤트를 자동 판정하고, 
Flask REST API를 통해 MySQL DB 저장과 메신저(슬랙/디스코드/텔레그램) 조건별 알림 전송을 일괄 처리하도록 구현했습니다.

**② 작업 내역**
파이썬 및 DB 구성 ->  n8n 구성 -> 메신저 수신 확인 -> 파이썬 코드 수정
